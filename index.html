O PROJETO

Uma plataforma de wallpapers do zero

O EclipseWall é um site para explorar e baixar wallpapers, com front-end em React e back-end próprio em ASP.NET, com banco de dados, login e controle de permissões.

Para quem usa

Navega por Popular ou Categoria, pesquisa pelo nome, carrega mais resultados, abre a página do wallpaper e baixa. Cada download é contabilizado.

Conta e permissões

Cadastro e login com JWT, senhas protegidas com BCrypt, ícone de perfil personalizável e upload de wallpapers liberado só para administradores.

POR DENTRO

        
O que tem debaixo

        

          

            01
            
Front-end React + Vite

            
Rotas com react-router-dom, estados com hooks, consumo da API com fetch e layout responsivo com clamp().

          

          

            02
            
API REST em ASP.NET

            
.NET 10 com controllers separados para usuários, wallpapers e ícones, usando DTOs para entrada de dados.

          

          

            03
            
Autenticação e permissões

            
Login com JWT, senhas com BCrypt e rotas protegidas com [Authorize] e roles para a área de administrador.

          

          

            04
            
PostgreSQL + EF Core

            
Modelos de Usuário, Wallpaper, Favoritos e Ícones, com migrations versionadas.

          

          

            05
            
Docker e Cloudinary

            
API empacotada com Dockerfile e integração com Cloudinary para imagens.

[HttpGet("VERIFY")]
[Authorize(Roles = "777")]   // só administrador
public IActionResult Verificar() => Ok();

[HttpGet("downloadslg")]
public async Task<IActionResult> Procurar(int slugid = 1)
{
    var objeto = await Bank.Wallpapers
        .FirstOrDefaultAsync(x => x.Id == slugid);

    if (objeto == null) return BadRequest("objeto nao encontrado");
    return Ok(objeto);
}
